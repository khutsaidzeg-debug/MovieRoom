# MovieRoom v2 — ქართული Watch Party

პირველი გაფართოებული MVP:
- ფილმების მთავარი კატალოგი
- ძებნა
- ფილმის დეტალური გვერდი
- ფილმიდან ოთახის შექმნა
- ოთახის მოწვევის ლინკი
- რეალურ დროში მონაწილეები
- რეალურ დროში ჩატი
- Play/Pause/Seek სინქრონიზაცია
- მობილური დიზაინი

## გაშვება
Node.js 18+:
npm install
npm start

შემდეგ: http://localhost:3000

## ონლაინ განთავსება
საჭიროა Node.js + WebSocket/Socket.IO მხარდაჭერის მქონე ჰოსტინგი.

## შემდეგი რეალური ეტაპი
1. PostgreSQL/MongoDB მონაცემთა ბაზა
2. რეგისტრაცია/ავტორიზაცია
3. ადმინისტრატორის პანელი
4. ფილმების რეალური კატალოგის მართვა
5. ოთახის პაროლი და owner permissions
6. HLS ვიდეოსტრიმინგი
7. მუდმივი ოთახები
8. რეაქციები და moderation

პოსტერების demo სურათები გამოყენებულია მხოლოდ ინტერფეისის დემოსთვის. ფილმების გავრცელება/სტრიმინგი უნდა იყოს უფლებამოსილი.
